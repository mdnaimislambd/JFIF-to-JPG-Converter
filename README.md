# JFIF to JPG Converter

Convert JFIF images to JPG right in your browser — fast, free, and completely private. **No uploads, no sign-up, no file size limits.**

**Live demo:** https://mdnaimislambd.github.io/JFIF-to-JPG-Converter/

## Features

- **100% client-side** — files never leave your device (no server uploads)
- **Batch convert** up to 200 files at once
- **Drag & drop, browse, or paste** images directly on the page
- **Quality control** — presets (65% / 92% / 100%) plus a fine-tune slider
- **Resize images** by max width or a custom width
- **Instant previews** with dimensions and file-size savings before downloading
- **Download individual JPGs or everything as one ZIP**
- **Mobile friendly** — works in any modern browser

## How to use

1. Drop your `.jfif` files onto the page (or click to browse)
2. Adjust JPG quality and resize options if needed
3. Click **Convert** and download your JPGs — one by one or all together as a ZIP

## Why convert JFIF to JPG?

JFIF (JPEG File Interchange Format) is a variation of the JPEG standard mainly used by cameras. It's mostly obsolete today — many apps, websites, and social platforms don't recognize the `.jfif` extension even though the image data is the same as a JPG. Converting to JPG makes your images compatible everywhere: websites, social media, documents, and photo editors.

## Privacy

This tool runs entirely in your browser using the Canvas API. Your images are never sent to any server, never stored, and disappear when you close the tab.

## Tech

- Pure HTML, CSS, and vanilla JavaScript
- Canvas API for instant local image encoding
- JSZip (loaded from CDN at runtime) for bulk ZIP downloads
